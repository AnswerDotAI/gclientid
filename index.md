# gclientid

Create Google OAuth desktop client IDs locally, without requiring `gcloud`.

`gclientid` is open-source software that runs on the developer's computer. It
creates a dedicated Google Cloud project and OAuth client owned by that
developer rather than sharing credentials through a hosted service.
